Entry for the [make.fun bounty](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9): the GPS's one-line excuse for sending the driver down the wrong road.

## The entry

> I sent you down that cul-de-sac because the map swore it was a shortcut. I believed it. You believed me. We were both wrong, but only one of us is a map.

## How it works

`main.ts` (Node 22, TypeScript as-is) writes the single-line excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and verifies the gate itself: 1–200 characters, one line, not blank.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
